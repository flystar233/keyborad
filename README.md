# 外壳 v1.3

基于 v1.2f 的 shell/cover 修改，所有位置取自 `PCB_PCB1_2026-10-11.pdf` 实测坐标。

## 输出文件（`out/`）

| 文件 | 说明 |
|---|---|
| `ESP32 BLE Keyboard v1.3 shell.stl` | 壳体，底面朝下打印，无需支撑 |
| `ESP32 BLE Keyboard v1.3 cover.stl` | 盖子，已翻转为打印方向（顶面朝下、螺丝柱朝上）。顶面按键凹槽处需要支撑（"仅从热床生成支撑"即可） |
| `ESP32 BLE Keyboard v1.3 cover (assembled).stl` | 装配位置的盖子，仅用于在切片/CAD 里检查干涉 |

## 相对 v1.2f 的修改

1. **USB-C 开孔**：从 x=-35.98 移到 USB0 实测位置 x=-38.45（原来偏了 2.47mm）。孔从 8.9×2.76 放大到 10.0×3.8（原孔比 3.26mm 高的母座还矮）。外侧加了 12.6×7.0 的让位槽，插头胶壳能插到底。
2. **SW1 侧按键**：后墙 x=42.45 处新开 Ø3.0 圆孔（中心高度 PCB 顶面 +1.7mm）。
3. **螺丝固定取代卡扣**：4 颗 M2 自攻螺丝从底部拧入：底面沉头孔 → 实心立柱 → PCB 角缺口 → 盖子下方螺丝柱。一套螺丝同时压住 PCB 和盖子。原来的卡扣槽和内壁卡扣凸点已去掉。
   - 推荐 **M2×14**（M2×12 也可以），盘头或圆柱头，头部直径 ≤4.0mm、高度 ≤2.0mm。
   - 沉头孔 Ø4.4 深 2.0；立柱通孔 Ø2.4；盖子自攻底孔 Ø1.7。
   - 右上角螺丝柱在 OLED 模块角的位置做了避让切角。
4. **按键孔**：14.0×15.0 → 15.4×15.6，开孔一直延伸到 PCB 顶面作为按键禁入区（螺丝柱靠按键一侧会被切平）。已验证：14mm 轴体偏移 ±0.3mm 且歪斜 ±3° 时与盖子零干涉。间距从 19.05 改为 PCB 实测的 19.09，并修正了 0.25mm 的 Y 偏移。

5. **底面刻字**：原有的 "ESP32-C3 BLE KEYBRICK / Designed by WilliTourt" 已填平。

未改动：整体外形、PCB 高度（底面 z=9.0）、盖子高度（16.3–18.3）、OLED 窗口、拨动开关 S 的孔、散热孔。

## 装配顺序

先焊好轴 → PCB 放到 4 根立柱上 → 盖上盖子 → 翻过来从底部拧 4 颗螺丝。

## 改参数

所有尺寸都是 `build_case.py` 开头的常量，改完重新运行：

pip install numpy trimesh manifold3d shapely networkx rtree
